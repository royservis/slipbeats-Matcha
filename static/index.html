Spotify

Spotify asks every app to be registered, even a private one. One-off setup:
  1. Go to developer.spotify.com/dashboard, log in with your Spotify account, Create app.
  2. Name it anything (e.g. Slipbeats). Redirect URI — copy exactly: . Tick Web API. Save.
  3. Open the app's Settings, copy the Client ID and paste it below. Then Connect — a browser tab opens to approve.
